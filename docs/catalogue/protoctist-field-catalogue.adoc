[preface]
== About this document

[.lead]
Protoctist.jl is a small Julia library for protist community analyses built on
PR2 or SILVA. This document proposes what it should grow into: one import that
gives a protistologist every method the field uses, by installing the Julia
packages that already do the work, building natively only what is missing, and
attaching to each result a statement of what the evidence does and does not
establish.

It is a review draft. Nothing in the catalogue is implemented because it is
listed here. Each entry says what exists today, what was tested, and what is
proposed.

[IMPORTANT]
.How to read the claims
====
Four words are used with fixed meanings throughout.

[.st-proven]#PROVEN# means a proof assistant accepted the statement, and the
entry names the repository and module. [.st-tested]#TESTED# means a program was
run and its result is reported; it is evidence about the cases run, not a
proof. [.st-assumed]#ASSUMED# means a premise taken from the literature.
[.st-open]#OPEN# means stated and not yet proved or tested.

A formula in this catalogue is the published definition of a method. Writing it
down does not mean Protoctist computes it today.
====
