= Roadmap

== 0.1.0 (current)

* Ladder-typed lineages (`:pr2`, `:silva`), with unfilled ranks kept in place.
* Taxonomy tree, count and evidence rollup, and clade cumulus.
* Lineage tables in CSV, TSV and ECSV, read back as a Tables.jl column table.
* jplace reading and writing, with every placement kept and selection by LWR.
* Newick/NHX and iTOL dataset export.
* Run manifests and a merge check over the judgement surface.
* No hard dependencies.
* Tested by Aqua and the behaviour suite, which runs the three worked examples
  under `examples/`.

== Candidates for the next release

These are open. Their order is not fixed.

Package extensions::
Load-time integration with EpistemicTypes.jl (receipt verification) and
Cladistics.jl (TaxonomyTree to a Cladistics tree), without making either a
hard dependency.

Classifier conventions::
Read QIIME 2 rank prefixes (`d__`) and a literal `NA` as unfilled ranks, as an
option at load time, instead of leaving that to the caller. See
link:../guide/troubleshooting.adoc#na-taxa[the NA pitfall].

Per-row attribution report::
List each row that was attributed to an ancestor because its full lineage was
not in the tree. Today this shows up only as a count on an interior node.

jplace fidelity::
Keep `nm` multiplicities and the `metadata` block when writing jplace.

iTOL label collisions::
Detect when two nodes share a label, and either disambiguate or refuse, since
iTOL datasets are keyed by label alone.
