== Changelog

All notable changes to this project will be documented in this file.

The format is based on https://keepachangelog.com/en/1.1.0/[Keep a
Changelog], and this project adheres to
https://semver.org/spec/v2.0.0.html[Semantic Versioning].

No release has been tagged. `0.1.0` is the version in `Project.toml` and the
release recorded in `CITATION.cff`.

=== [Unreleased]

==== Changed

* The package UUID was re-minted as a UUIDv8 (estate ADR-008 amendment D320).
  The previous UUIDv5 is in the git history of `Project.toml`.
* `read_ecsv` and the structs with `Vector` fields were changed so that JET
  reports no findings (it reported 18). The source follows JuliaFormatter 2.14.
* `load_protist_run` accepts `sep=`, so DADA2 and QIIME 2 TSV exports load
  directly.
* *Breaking:* `Standpoint`, `Warrant` and `ProjectionY` are renamed
  `LineageStandpoint`, `LineageWarrant` and `LineageProjection`. EpistemicTypes.jl
  owns the evidence vocabulary, and the same names with different fields made
  `using EpistemicTypes, Protoctist` ambiguous.

==== Fixed

* `read_jplace` kept only the first candidate of each query's `p` array and
  the first name of `n`/`nm`. It now returns one `Placement` per (name,
  candidate) and reads `null` fields as `NaN`. `write_jplace` groups the
  candidates back into one object per query, and `best_placements` selects by
  highest `like_weight_ratio`, not by position.
* `read_jplace` read only the compact `[[...]]` form of `p`, so a pretty-printed
  file, with whitespace between those brackets, gave no placements and no
  error. Whitespace is now allowed.
* `best_placements` kept a first candidate whose ratio was `null` (`NaN`) over a
  later numeric ratio. A `NaN` ratio now never wins over a number.
* `load_protist_run` read an unparseable count (`NA`, blank, `12.5`) as 0 and
  so dropped reads from every rollup. It now throws an `ArgumentError` that
  names the file, row and column. Integral floats such as `12.0` are accepted.
* A lineage with a closing `;`, as SILVA and QIIME 2 write it, no longer gets
  an extra rank. Trailing blanks are dropped; interior blanks (unfilled ranks)
  are kept.
* `write_ecsv` quotes a field that contains the separator in use, not only a
  comma, so space- and tab-separated files round-trip QIIME 2 lineages.
* Docstrings no longer claim a package extension, receipt verification or a
  phylogeny that 0.1 does not provide.
* `CHANGELOG.adoc`, `STATE.a2ml` and `ECOSYSTEM.a2ml` described the repository
  template this package was minted from, not the package.

==== Added

* `docs/guide/`: a cookbook (DADA2 with PR2 to iTOL, QIIME 2 with SILVA, EPA-ng
  placements, pooled runs), lineage formats, troubleshooting and a glossary.
* `examples/dada2`, `examples/qiime2` and `examples/epa-ng`, run by
  `test/cases/examples.jl`.
* `docs/ARCHITECTURE.adoc`, the design decisions in `docs/EXPLAINME.adoc`, and
  real citation keywords and the author's ORCID in `CITATION.cff`.

==== Removed

* `.github/workflows/rust-ci.yml`. The package has no Rust code.
* The template's documentation, `features/` and the unwired Idris2/Zig
  skeleton under `src/`.

=== [0.1.0] - 2026-09-23

==== Added

* An implementation of the Protoctist design from the thread "Clades and Other
  Prompts". The thread held no Protoctist source, so `src/` is written from the
  design; the recovered material is in `docs/recovered/`.
* `src/types.jl`: the PR2 (9 ranks) and SILVA (7 ranks) ladders, `TaxPath`,
  `EpiStatus`, `EvidenceReceipt`, `ResidualInfo`, `Standpoint`, `Warrant` and
  `ProjectionY`.
* `src/tree.jl`: the taxonomy tree, cumulative rollup and annotated Newick
  (NHX).
* `src/io.jl`: ECSV read and write, jplace read and write, and iTOL dataset
  export.
* `src/manifest.jl`: run manifests and the merge check.
* The test suite: Aqua package-shape checks, then behaviour tests in
  `test/cases/`.
