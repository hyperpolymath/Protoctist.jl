Integration library unifying types, IO and exports for PR2/SILVA-driven protist workflows


== What this is

`Protoctist.jl` is the *single import point for protistologists*: a small Julia
package that unifies the types, IO and exports used by PR2/SILVA-driven protist
workflows.

It is deliberately small. It *composes* the surrounding libraries rather than
duplicating their logic — the design's own words: "It does not duplicate logic —
it composes the three existing libraries."

* `EpistemicTypes.jl` — receipts, `epi_status`, residual summaries, merge check
* `Cladistics.jl` — LCA, cumulative rollups, annotated Newick
* `EchoTypes.jl` — spec tests (test-only, never on a hot path)

[NOTE]
====
Those three are *not yet hard dependencies*. The evidence vocabulary and the
taxonomy trie are defined here so that `using Protoctist` works today, in a bare
environment, with nothing else published. When a sibling package is present the
matching extension defers to it. This keeps an honest green: the package really
does load and really does pass its tests, rather than declaring dependencies that
do not yet exist.
====

=== Provenance — this package was recovered, not written from scratch

The design for this library existed only inside a chat thread on Arena.ai
("Clades and Other Prompts", 2026-09-16) and had never been pushed anywhere. It
was recovered on 2026-09-23 by sweeping the full 449-conversation account index.

`docs/recovered/` holds the material it was rebuilt from — the design spec and
all 23 Julia code blocks from the thread. `src/` is a faithful implementation of
that design; there was no Protoctist source file to restore, because none was
ever written. Where the design named a behaviour without pinning it down, the
choice made here is documented at the definition site.

== Quick start

[source,julia]
----
using Protoctist

# Load a merged table, build the taxonomy tree, roll the evidence up
run = load_protist_run("merged.ecsv")          # -> ProtistRun

# Cumulative counts per clade, deepest-first ("clade cumulus")
for (taxon, n) in clade_cumulus(run)[1:10]
    println(taxon, "\t", n)
end

# Annotated Extended Newick + an iTOL-ready bundle
export_iqtree_annotated(run, "out/")
----

Lower-level entry points follow the recovered module skeleton:

[source,julia]
----
Protoctist.Types      # TaxPath, EvidenceReceipt, EpiStatus, ResidualInfo,
                      # Standpoint, Warrant, ProjectionY, PR2/SILVA ladders
Protoctist.Tree       # build_taxonomy_tree, rollup_counts, annotate_newick
Protoctist.IO         # read_ecsv/write_ecsv, read_jplace/write_jplace,
                      # export_itol_bundle
Protoctist.Manifest   # build_manifest, validate_merge
----

=== Rank ladders

PR2 (9 ranks) and SILVA (7 ranks) are both supported, and are *not*
interchangeable — a `TaxPath` carries its ladder, and two paths on different
ladders are never equal. A blank rank is an *unfilled* rank, not the end of a
lineage: PR2 routinely leaves `subdivision` empty for lineages that do reach
genus, so truncating there would silently discard exactly the Giardia and
Cercozoa lineages this package exists to handle.

== AI-Assisted Installation

If you are an AI agent installing this project, read
link:docs/AI_INSTALLATION_GUIDE.adoc[the AI installation guide] first — it gives
the orientation order, the full prompt sequence, and the privacy notice.

The one trap worth stating up front: **do not set `RSR_NON_INTERACTIVE=1`**. It
stubs the shell builtin `read`, which also disables the loops that perform token
substitution — the run never terminates and substitutes nothing. Pipe answers to
stdin instead.

== What you get

* *Machine-readable metadata* (`.machine_readable/descriptiles/`) — `STATE`, `META`,
  `ECOSYSTEM`, `PLAYBOOK`, `AGENTIC`, `NEUROSYM`, `CLADE`, and `anchors/ANCHOR`,
  in deed, so tools and agents can read the project's state and boundaries.
* *AI gatekeeper protocol* — `Protoctist.jl_chora.deed` (the repo deed) is the
  universal entry point that tells an AI agent how to work in this repo before it
  touches anything; it carries the AI allocation policy and the ply directory tree.
* *Typed ABI/FFI seam* — `src/interface/Abi/` (Idris2 type + layout proofs) over
  `src/interface/ffi/` (Zig implementation), with generated C headers.
* *CI/CD* — GitHub Actions for quality, security (CodeQL, Scorecard, secret
  scanning), multi-forge mirroring, and RSR anti-pattern enforcement.
* *Supply-chain & reproducibility* — container layering (stapeln), Guix shells,
  SBOM, and signing hooks.
* *Governance* — `GOVERNANCE.adoc`, `MAINTAINERS.adoc`, `.github/` community health
  files, and a release `AUDIT.adoc` gate.
